# API Reference

Explore the full API for Nextra components and hooks.

## Components

### Callout

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `type` | `string` | `'default'` | The type of callout (default, error, warning, success) |
| `emoji` | `string` | `''` | An optional emoji to display |
| `children` | `ReactNode` | `undefined` | The content of the callout |

### Card

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | `undefined` | The title of the card |
| `href` | `string` | `undefined` | The target URL |
| `icon` | `ReactNode` | `undefined` | An optional icon to display |

## Hooks

### `useMDXComponents`

Used to provide custom components to the MDX environment.
